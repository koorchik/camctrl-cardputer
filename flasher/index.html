CamCtrl Cardputer

A handheld remote for Blackmagic cameras. Plug the Cardputer ADV into the camera's USB‑C port: one‑press autofocus, focus, iris, shutter, ISO, white balance, tint and clean feed on its own screen and keyboard. Phones with the CamCtrl app control the camera over its Wi‑Fi at the same time.

Install from this page

  1. Use Chrome or Edge on a computer (the browser talks to the board over USB).
  2. Connect the Cardputer ADV to the computer with a USB‑C data cable.
  3. Start the download mode: power switch off, hold G0, switch on, release.
  4. Click the button, pick the serial port, confirm.
  5. When it is done, switch the Cardputer off and on again.

For the Cardputer ADV only (it needs the ADV's keyboard controller).

This browser cannot flash boards. Use Chrome or Edge on a computer. Open this page over https to flash.

Then

  1. Camera network settings: DHCP.
  2. Set the Cardputer's own power switch OFF and plug it into the camera's USB‑C port. It runs from the camera.
  3. The screen walks through USB → network → camera, then shows two cards with the keys. h shows all keys at any time.

Tested with a Blackmagic Micro Studio Camera 4K G2. Source, documentation and issues: github.com/koorchik/camctrl-cardputer. The Wi‑Fi bridge comes from EthAir.
